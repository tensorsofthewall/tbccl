tbccl uses the TBCCL Geometric Crossing mark next to its package name.
The mark is shared by the TBCCL projects and is never redrawn or recoloured. tbccl uses no logo, symbol or mascot of any other project.

## Using the artwork

- The files are in `branding/lockups/` in the repository: horizontal, compact and stacked lockups, each in a light, a dark and two monochrome (black and white) version. Use the light version on light backgrounds and the dark version on dark ones.
- Use the horizontal lockup at 24 px tall or larger; the compact lockup is for small placements such as navigation. The documentation sidebar keeps the compact mark and the project name.
- Do not stretch, recolour, outline, rearrange or combine the lockups with other logos.
- The lettering is converted to outlines, so the files need no font. It was set in Inter SemiBold (SIL Open Font License 1.1, copyright The Inter Project Authors); no font file is distributed. `branding/lockups/MANIFEST.json` records the font version, the generator and a checksum of every file.
- The canonical artwork and the generator live in the [TBCCL repository](https://github.com/tensorsofthewall/tbccl/tree/main/branding).
