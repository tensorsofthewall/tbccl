# TBCCL 0.6.1 validation (draft)

```{warning}
**This is not a certification.** TBCCL 0.6.1 is a patch release of 0.6.0 that adds the public benchmark suite (C ABI 1, wire protocol 4, endpoint blob format 1). The runtime evidence of the previous release stands because no runtime code changed; this page records what is specific to 0.6.1. The release has not been published yet, so the release-artifact checks below are listed as not done.
```

## What changed

The Python benchmark suite (`benchmarks/suite`), its documentation and the provider protocol. There is no change under `src/` or `include/`, and no transport or collective change; the native tests of 0.6.0 therefore apply unchanged and are not repeated here.

## Benchmark suite tests

The suite tests (763) pass on Linux and macOS in a framework-free CPython 3.13 environment with only PyYAML: capability discovery, profiles, the quick profile on loopback, report generation in four formats, comparison and its three-state build identity (matching, different, unknown), historical result compatibility, provider validation and remote supervision, cleanup, and the privacy tests (no private paths or addresses in recorded provenance).

## From the source archive

The source archive of the release tree (`git archive`, no `.git`) builds the native benchmarks, passes `doctor` and runs the `quick` profile to 20 of 20 successful points without PyTorch, vLLM, Exo or MLX.
