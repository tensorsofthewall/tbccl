## Reproducibility

- Transport: TCP over ThunderboltIP
- MTU: 9000
- TCP_NODELAY: on
- GRO: on
- Trials per cell (observed): 10
- Busy-poll configurations: 0 µs, 100 µs
- Linux affinity: CPU 0 (P-core) where applicable, via `taskset -c 0`

Hardware:

- Mac: base M4 Mac mini, 16 GB, Thunderbolt 4
- Linux: i7-12700HX / RTX 3070 Ti laptop

These numbers are specific to this pair of machines and this Thunderbolt link. They are not presented as representative of Thunderbolt networking in general.
